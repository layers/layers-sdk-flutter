# Layers SDK for Flutter

## Installation

Add to your `pubspec.yaml`:

```yaml
dependencies:
  layers_flutter: ^1.0.0
```

Then run:

```bash
flutter pub get
```

## Requirements

- Flutter >= 3.10.0
- Dart >= 3.0.0
- iOS 14+ / Android API 21+

## Documentation

See [docs.layers.com](https://docs.layers.com) for integration guides.
